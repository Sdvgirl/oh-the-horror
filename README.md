# The Open Door

A point-and-click pixel-art psychological horror game. Your only goal: get groceries.

Everything (pixel art, lighting, rain, music box, heartbeat, knocks) is generated in code. No assets, no build step.

**Controls:** click or tap anything to look at it or use it. Works on desktop and mobile. Headphones recommended.

## Publish on GitHub Pages
1. Create a repo and add `index.html` and this README at the root.
2. Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Your game goes live at `https://<your-username>.github.io/<repo-name>/`.
